## 官方技术与行业源核验

### 有效新增

1. [Hugging Face LeRobot：用缓存的单列视图加速 delta query](https://github.com/huggingface/lerobot/commit/fbb811fca92504439792b97d216f0d00c2268382)
   - 提交时间：2026-09-02 04:56（北京时间）。
   - `datasets>=4.4` 下，自定义 transform 会让按列索引退化为整行读取；在图像数据集上，即使只读取 action 或 timestamp，也会解码每个相机图像。
   - 修复通过缓存 `select_columns` 单列视图恢复零拷贝 schema projection，并在 transform 变化时失效缓存。官方提交给出的基准为查询约 200 倍、含 50 步 action chunk 的端到端单样本约 46 倍加速。
   - 学习价值：机器人训练数据优化不能只看 DataLoader worker 数量；应测量“取低维 action 时是否误解码多视角图像”，并为缓存设计明确的失效条件。

2. [NVIDIA Cosmos Framework：2026-09-02 自动发布](https://github.com/NVIDIA/cosmos-framework/commit/9f008aeaaa1ee7dcb623a0319799c4aba72e8058)
   - 提交时间：2026-09-02 15:54（北京时间）。
   - 本次 release train 增加 Lance VLM 无放回采样的可恢复游标、推理 text-KV cache、cond/uncond 合批 CFG 路径，并补齐无相机 LiDAR-only batch 的训练处理。
   - 学习价值：世界模型的工程瓶颈已深入到可恢复数据游标、分布式推理路径一致性、KV 复用和异构传感器流；这比只会运行单卡 demo 更接近真实训练/部署系统。

3. NVIDIA Cosmos Framework：动作策略数据链扩展
   - [DROID 复合视图增强优化](https://github.com/NVIDIA/cosmos-framework/commit/0d9e8fec373d32503f856f8960aa11ba92e5f3c1)，提交时间：2026-09-02 17:06（北京时间）。将数据增强作用于 DROID composite，而不是分别处理三张全尺寸视图，减少重复的大图像处理开销。
   - [RoboCasa 移动操作 action-policy 支持](https://github.com/NVIDIA/cosmos-framework/commit/245d2b934c1a0a164d55193b90f724cc99760473)，提交时间：2026-09-02 20:24（北京时间）。新增 LeRobot loader、dataset factory、Nano 后训练配置、embodiment 注册和闭环评测脚本；15 维 raw action 同时覆盖移动底盘、控制模式、末端位姿和夹爪，观测由左侧 agent view、腕部视角和 EEF 本体状态组成。
   - 去重说明：两次提交都服务于 Cosmos action-policy 数据与训练链路，合并为一个更新簇；RoboCasa 是移动操作的新 embodiment，DROID 是已有数据路径的增强效率修正，不按文件数量扩张计数。

4. [澎湃新闻：具身数据从固定训练场转向真实场景闭环](https://m.thepaper.cn/newsDetail_forward_33993034)
   - 发布时间：2026-09-02 15:44（北京时间）。
   - 报道汇总了无本体分布式采集、60FPS / 1080P / 双目 / 深度、时间同步与空间标定、自动检查与人工审核，以及“部署—出错—接管—回流—训练—再部署”的数据闭环。
