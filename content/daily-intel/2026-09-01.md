## 官方技术与行业源核验

### 有效新增

1. [Hugging Face LeRobot：开放数据读取器注册机制](https://github.com/huggingface/lerobot/commit/fa048804d05c1b965b0a5801cf205f97a9e8a3e8)
   - 提交时间：2026-09-01 17:38（北京时间）。
   - 新增 `register_dataset_reader`，允许第三方存储格式注册自己的读取模块；远程根目录探测遇到可选依赖缺失时会继续尝试其他后端，而不是中断。
   - 同簇更新包括 [Lance 数据集可在 Foxglove 回放](https://github.com/huggingface/lerobot/commit/d36d404b65315139b7601a707f260a3db736462f)（09-01 00:36）和 [map-style bucket 支持 `eval_split`](https://github.com/huggingface/lerobot/commit/128d3324e3202ce1fca1340fb8d7941edecce9d3)（09-01 19:41）。三次提交均延续 08-29 已收录的 LanceDB 主变更，合并为一个“多存储后端可训练、可评测、可回放”的工程更新簇。
   - 学习价值：数据层不再绑定单一 Hugging Face Dataset 形态，训练、评测和可视化可以共享统一读取契约；适合用于大规模机器人数据流水线与对象存储实践。

2. [Hugging Face LeRobot：修复 HIL-SERL 固定复位姿态编码](https://github.com/huggingface/lerobot/commit/dd256899946c6255653aa7824a9f8ce6420148b4)
   - 提交时间：2026-09-01 15:37（北京时间）。
   - 将 `ResetConfig.fixed_reset_joint_positions` 从不可被 draccus 编码的 `Any` 改为准确的 `list[float] | None`。
   - 官方提交说明指出，所有示例 HIL-SERL 配置都会设置复位姿态，旧类型会让 learner 在数据集、策略或 gRPC 服务构造前直接报错；修复后示例配置可进入 learner 线程并加载离线 replay buffer。
   - 学习价值：这是一个直接解除仿真与真机 HIL-SERL 启动阻塞的配置修复，提醒课程实践把“配置序列化—环境复位—安全姿态”纳入部署检查表。

3. [NVIDIA Cosmos Framework：2026-09-01 自动发布](https://github.com/NVIDIA/cosmos-framework/commit/107f79ba3d6d2f7c9ef767be6692c03ffacf4a05)
   - 提交时间：2026-09-01 17:56（北京时间）；与窗口内的 [2026-08-31 自动发布](https://github.com/NVIDIA/cosmos-framework/commit/d4599e2e43fbd06168e9884205b9b66c3902d8f6)（08-31 23:50）合并为一个连续发布簇。
   - 09-01 发布新增交互式因果 Omni-MoT、causal attention / context parallel、KV cache 与存储后端、teacher forcing、CUDA Graph / static compile、NVFP4，以及面向动作数据的 caption 属性适配和相机轨迹工具。
   - 08-31 发布补入统一 action schema、VAE load balancing、FlexAttention、Flow Matching loss 与生成成本模型等训练/部署能力。
   - 学习价值：从“世界模型生成结果”推进到可持续交互、缓存复用、并行与低精度部署的系统工程链路；两次自动发布属于同一仓库的连续 release train，不按文件数重复计数。

4. [小鹏汽车：第二代 VLA 首次重大升级](https://www.xiaopeng.com/news/company_news/5591.html)
   - 官网发布日期：2026-09-01；正文所述体验日发生于 2026-08-27，按“本窗口新增官方发布”纳入，并明确区分事件日期与网页发布日期。
   - 官方说明将核心变化概括为从静态 3D 空间理解走向动态 4D 时空理解：端侧模型参数量扩大 3.5 倍，引入超长时序上下文、整车 Master Agent 的 VLA + VLM 融合，并通过 Token 压缩与蒸馏将能力下放到较低算力平台。
   - 官方同时说明该统一物理 AI 基座正在向 IRON 机器人本体延伸；学习价值集中在长时序记忆、VLA/VLM 协同与端侧蒸馏，而不是把自动驾驶产品指标直接等同于机械臂策略指标。
