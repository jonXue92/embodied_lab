### 1. LeRobot 修正 π0/π0.5 的 tokenizer 与 PEFT 目标配置

- 原始链接：[可配置 PI tokenizer 675c0766](https://github.com/huggingface/lerobot/commit/675c07664279659525b1d1e52b6e33538c957ee3)、[π0.5 time MLP PEFT 修复 9758537d](https://github.com/huggingface/lerobot/commit/9758537d928ed2e315422e76d4f4c8050c0c6c00)。
- 提交时间：2026-09-07 20:41:25、20:16:11（北京时间）。
- 文件级核验：PI0Config/PI05Config 新增 text_tokenizer_name，processor 不再硬编码 PaliGemma tokenizer，并用本地 tokenizer 测试 config 保存/恢复与 token/mask shape；π0.5 默认 PEFT regex 从不存在的 action_time_mlp 名称改为真实 time_mlp_in/out，补测试确保正确模块被 LoRA 命中。
- 学习价值：配置能序列化不代表它真正连接到 processor/模块。VLA 微调应列出 tokenizer 身份、max length、PEFT 命中模块和可训练参数数目，并用负例检查不存在的名字不会被悄悄接受。

### 2. LeRobot 修复采集 reset、量化统计与对象存储根路径边界

- 原始链接：[reset 保持压缩图像设置 2774d9bd](https://github.com/huggingface/lerobot/commit/2774d9bddcbbda50e697e162e89e7eaada8d7105)、[skip-images 同时禁止视频下载 c23698e2](https://github.com/huggingface/lerobot/commit/c23698e27251a72dfdcef81c51fb6071367036c7)、[对象存储 URI 保持字符串 77678397](https://github.com/huggingface/lerobot/commit/776783975ec68f85b6016404f8ac0423f4d137b0)。
- 提交时间：2026-09-07 20:52:13、20:30:33、20:04:28（北京时间）。
- 文件级核验：record 在 episode reset 的 record_loop 也传入 display_compressed_images，避免同一可视化后端混收压缩/未压缩消息；quantile stats 创建 LeRobotDataset 时把 download_videos 绑定为 not skip_images；dataset viz 的 root 从 Path 改为字符串，避免 s3 URI 被本地路径规则破坏。
- 学习价值：这些改动共同说明数据管线的“同一个选项”必须跨录制、reset、下载和读取边界保持语义；只检查主循环或文件是否存在，无法证明离线数据任务可复现。

### 3. LeRobot 暴露 W&B resume 与 console 设置

- 原始链接：[LeRobot ed006149](https://github.com/huggingface/lerobot/commit/ed00614903324ab19c52f8719f69633902ab2d1f)。
- 提交时间：2026-09-07 20:33:44（北京时间）。
- 文件级核验：WandBConfig 增加 resume、console、console_multipart 和 console_chunk_max_seconds，WandBLogger 把设置传入 wandb.init / wandb.Settings；未显式配置时，训练 checkpoint resume 仍保持 must。
- 学习价值：实验追踪的 run 恢复策略与模型 checkpoint 恢复是两份状态。若两者不一致，训练可能正确续跑却写入错误 run，或日志续上但 optimizer/scheduler 已重置；9 月 13 日 checkpoint 课程应把二者一起审计。

### 4. Cosmos Framework 发布多视角文本、条件帧模式与动作域对齐

- 原始链接：[NVIDIA Cosmos Framework fcd1d7eb](https://github.com/NVIDIA/cosmos-framework/commit/fcd1d7eb07ad76dd7f15c61185a2377f15918ac7)。
- 提交时间：2026-09-07 11:13:23（北京时间）；这是基于内部 6d357d20-dirty 的唯一公开自动 release，按 1 个发布簇计数。
- 文件级核验：SequencePlan 支持命名 t2v/i2v/v2v/frame_interpolation，插帧模式在首帧外抽第二条件帧；多视角 caption 可按 view 分别 tokenize，并保留 ragged token/length 边界和 sample_n_views 校验；action_domain_id 支持标量或逐 action token 对齐，在 pack、noisy index、teacher-forcing 截断和 autoregressive chunk 中同步切片；位置嵌入 resize 在 deterministic algorithms 下使用确定性矩阵 adjoint。
- 边界：同一 release 中 omni_mot_model 对 separate-view token length 仍显式抛 NotImplementedError，说明 tokenizer/dataloader 支持已进入，但 grouped sequence-packing/attention 尚未完整打通。14:33 的后续 4e0fe142 只更新 .file_mapping.json，不另计实质更新。
- 学习价值：多视角文本、动作域和时间条件都必须随 pack/chunk 的索引一起移动；“字段存在”不等于训练路径端到端支持，显式失败比静默错位更可靠。
