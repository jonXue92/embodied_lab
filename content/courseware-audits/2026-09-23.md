## 人工内容复读

- 公式：`A^k=sqrt(alpha_bar_k)A^0+sqrt(1-alpha_bar_k)epsilon` 与 epsilon MSE 一致；alpha_bar=0.64 时信号/噪声系数为 0.8/0.6。20 Hz 执行 4 步是 0.2 s，未把 horizon=16 误写成全部开环执行。
- 代码行为：基础例精确恢复 A0，人工偏移 0.1 得 MSE 0.01；TinyDiffusion 对每样本 timestep 广播，梯度非零，同固定 noise 采样可复现，全 padding 被拒绝；时延例得到计划 52/82/142 ms 与 -77 ms 负余量。
- 简化边界：TinyDiffusion 不含视觉 encoder、1D U-Net 多尺度结构、EMA 或 diffusers 完整 DDPM/DDIM 方差处理；教学反向式只保留确定性接口，不冒充上游 checkpoint 兼容实现。
- 相邻日差异：09-25 ACT 用 posterior style latent 与 action query 一次解码，标准部署 z=0；09-26 从高斯动作块多步去噪；09-27 将学习连续 flow target 与 Euler 积分，不提前混同离散 scheduler 和连续向量场。
