## 新备课程范围

### 2026-10-08 · checkpoint 与冻结

- 基础课把 checkpoint 定义为权重、config、processor、stats 与 dataset identity 的联合资产，区分加载权重微调和恢复 optimizer/scheduler/step 的完整 resume；用投影算子解释冻结子空间。
- 代码课定位 `set_requires_grad`、`train()` 与 `lerobot_train.py` 的可训练参数/optimizer 路径，实现参数名、module mode 和首批 gradient 三重审计，负测拒绝解冻泄漏。
- 路线课给出 expert-only→视觉尾层→部分 VLM→全量微调阶梯，要求同 checkpoint、split、processor 和有效样本预算；双团队仅作为表征/仿真独立对照。

### 2026-10-09 · flow action expert

- 基础课推导 noise-at-one：`x_t=(1-t)a+tε`、`u_t=ε-a` 与负时间 Euler；明确 flow 时间、chunk 位置和物理控制时间是三条轴。
- 代码课对应 `VLAFlowMatching.forward/sample_actions` 与外层 padding reduction，原创 mask-aware loss 以显式 noise/time 验证目标符号、有效分母和全 padding 拒绝。
- 路线课联合选择 Euler steps、chunk size 与执行步数，使用误差—p99—观测年龄—安全 Pareto 门，不从默认 10 步或论文硬件外推个人设备。

### 2026-10-10 · 异步推理与 action queue

- 基础课拆分 RobotClient/PolicyServer，推导 `Q_trigger≥ceil(fT99)+J`，同时设置 observation age 上限；解释 server 最新观测覆盖与 TimedAction 防乱序。
- 代码课定位 handshake、发送/接收线程、queue lock 与重叠 chunk，原创合并器只接受同 session 的未来 timestep，负测拒绝倒序/重复；空队列返回 STOP，不包含控制命令。
- 路线课比较本地/云端 capture-to-execute 分布、故障注入和数据授权；客户数据授权是非补偿硬门。

### 2026-10-11 · 离线评测与回放

- 基础课区分 teacher-forced、open-loop replay 和 closed-loop rollout，推导 mask-aware MAE，并要求按关节、horizon、阶段、场景和失败类型切片。
- 代码课定位 `lerobot_eval.py` 的 rollout、mask、reward/success、seed、视频与 episode data，原创 trace validator 检查 episode identity、连续 frame、单调时间、终止和摘要重算。
- 路线课建立 L0 单元—L1 离线—L2 仿真—L3 经授权真机证据阶梯，严重事件使用硬停止；StanfordVL/World Labs 与 Meta/FAIR/AMI 各自归属未混写。
